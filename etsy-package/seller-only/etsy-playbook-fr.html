Description complète

🧠 Face Quest — un labo de reconnaissance faciale dans le navigateur pour les enfants, les classes et les makers. Ouvrez un fichier HTML dans Chrome ou Edge, autorisez la webcam, et apprenez votre visage à l'appli. Trois petits modèles d'IA tournent entièrement sur votre portable — aucune photo sauvegardée, aucun cloud, aucun compte. CE QUE VOUS RECEVEZ • 📷 Scanner de visage en direct avec miroir, bascule de caméra et scanline • 🧠 « Teach My Face » : enrôlement 1:1 (échantillons nets, descripteur de 128 nombres) • 🔓 « Unlock » : boucle de vérification MATCH / NO MATCH + XP de gamification • 📐 Seuil réglable (Euclidienne ou Cosinus), détecteur SSD ou Tiny • 🔒 Verrouillage automatique après quelques secondes sans visage • 🔑 Test Mode protégé par un code PIN à 4 chiffres pour les démos en continu • 🎤 Commandes vocales (« Start », « Teach », « Unlock », « Lock », « Reset ») + 🔊 retour parlé • 🤖 Lien BLE UART vers un BBC micro:bit V2 — MATCH / NO / ENROLLED / LOCK / TEST • 🧾 Console Quest Log horodatée et colorée • 📱 PWA installable — fonctionne hors ligne après le premier chargement CONTENU DU TÉLÉCHARGEMENT • index.html, app.js, styles.css — l'appli Face Quest Lab complète • face-api.min.js + /models — les 3 cerveaux d'IA inclus • ble_microbit.js + microbit.ts — firmware Robot Buddy pour MakeCode • README.md — vue d'ensemble accessible aux enfants • USERGUIDE.html & .md — installation complète + dépannage • Imprimables : carte démarrage A4, aide-mémoire des contrôles A4, poster de classe A3, plan de cours 45 min, 30 stickers • LICENSE — licence personnelle / classe mono-utilisateur CONFIGURATION REQUISE • Une webcam (intégrée ou USB) • Chrome ou Edge sur ordinateur (getUserMedia + Web Bluetooth) • Un moyen de servir le dossier en HTTP local (le guide montre python3 -m http.server) • Optionnel : BBC micro:bit V2 pour la démo Robot Buddy POUR QUI ? Enseignants qui font de l'éducation à l'IA · familles en IEF · clubs robotique & code · makers qui prototypent de la reconnaissance on-device · enfants curieux à partir de 9 ans. VIE PRIVÉE D'ABORD Aucune photo n'est sauvegardée. face-api.js tourne dans votre navigateur ; seul un descripteur de 128 nombres vit dans IndexedDB, que vous pouvez effacer avec Reset Face. Aucun compte, aucun cloud, aucune télémétrie. Jamais. MISES À JOUR À VIE Chaque version publiée depuis cette annonce est à vous pour toujours.
