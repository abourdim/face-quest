Description complète

🎮 Face Quest — un jeu de reconnaissance faciale par IA pour enfants, 100 % dans le navigateur. Ouvrez un seul fichier HTML dans Chrome ou Edge, montrez votre visage à la webcam, et l'appli apprend qui vous êtes en 3 secondes. Puis elle se déverrouille, vous souhaite la bienvenue, et transforme l'apprentissage de l'IA en quête gamifiée — sans qu'aucune donnée ne quitte votre machine. CE QUE VOUS OBTENEZ • 🧠 Flux « Apprends ton visage » — enregistre un visage avec quelques images de webcam, calcule un descripteur 128-D localement • ⚡ Flux Vérifier / Déverrouiller — la correspondance en direct renvoie MATCH ou NO-MATCH en ~200 ms • 🎙 Commandes vocales — « start », « teach », « unlock », « lock », « reset » via l'API Web Speech • 🔊 Retour vocal — l'appli lit elle-même son statut (« Face learned. You're ready to unlock. ») • 🔒 Mode auto-lock — protégé par PIN ; se verrouille quand le visage quitte le cadre, se déverrouille sur une correspondance • 🏆 Quest Log + compteur XP — boucle de récompense gamifiée qui fait revenir les enfants • 🔁 Bascule caméra avant/arrière + effet miroir • 📡 BBC micro:bit V2 optionnel en BLE UART — l'appli envoie MATCH / NO → ✓ ou ✗ sur les LEDs 5×5 • 🛡 Vie privée par conception — pas de cloud, pas de compte, les descripteurs ne vivent que dans localStorage • 📱 PWA — installable, utilisable hors ligne après le premier chargement • 👶 Interface enfant + 🧙 Contrôles PIN pour parents / enseignants CONTENU DU TÉLÉCHARGEMENT • index.html — le jeu de reconnaissance faciale complet • modèles face-api.js — poids TensorFlow.js embarqués en local, aucun appel CDN • makecode.ts — firmware micro:bit optionnel (à flasher une fois depuis MakeCode) • SETUP.md — démarrage rapide en 5 minutes • docs/ — guide illustré, fiche pédagogique prof, FAQ, playbook Etsy • LICENSE — licence mono-utilisateur personnelle / classe PRÉREQUIS • Webcam (la cam intégrée du portable suffit) • Chrome ou Edge sur ordinateur (ou Chrome sur Android) • Microphone (pour les commandes vocales — optionnel mais recommandé) • BBC micro:bit V2 + Bluetooth (optionnel, pour le retour LED) • HTTPS ou file:// — un double-clic sur le HTML suffit POUR QUI Enseignants qui introduisent l'IA en classe · familles en école à la maison · clubs de robotique et STEM · parents qui veulent un premier contact sûr avec la reconnaissance faciale · toute personne curieuse de voir comment face-api.js et TensorFlow.js fonctionnent vraiment. CONFIDENTIALITÉ D'ABORD Rien ne quitte votre ordinateur. Jamais. Les images de la webcam ne quittent jamais l'appareil. Pas d'analytique, pas de connexion, pas de cloud. Le descripteur facial 128-D ne vit que dans le localStorage du navigateur et peut être effacé d'un clic. MISES À JOUR À VIE Chaque version publiée depuis cette annonce est à vous pour toujours. Retéléchargez le dernier ZIP à tout moment depuis votre page Achats Etsy. Bonne quête ! 🚀🧠🎮
