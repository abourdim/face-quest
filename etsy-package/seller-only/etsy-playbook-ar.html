الوصف الكامل

🧠 Face Quest — مختبر تعرّف على الوجوه يعمل داخل المتصفّح للأطفال والصفوف وعشّاق الميكِر. افتح ملف HTML واحدًا في Chrome أو Edge، اسمح بالكاميرا، وعلّم التطبيق وجهك. ثلاثة نماذج ذكاء اصطناعي صغيرة تعمل بالكامل على حاسوبك — لا تُحفظ أيّ صور، لا سحابة، لا حساب. ماذا تحصل • 📷 ماسح ضوئي للوجه مباشر مع مرآة، وتبديل كاميرا، وتأثير خطّ المسح • 🧠 «Teach My Face»: تسجيل 1:1 (عيّنات واضحة، واصف من 128 رقمًا) • 🔓 «Unlock»: حلقة تحقّق MATCH / NO MATCH + تحفيز XP • 📐 عتبة قابلة للضبط (إقليدية أو جيبية)، كاشف SSD أو Tiny • 🔒 قفل تلقائي بعد ثوانٍ دون وجه في الإطار • 🔑 وضع اختبار محمي برمز PIN من 4 أرقام للعروض وملوّنة • 📱 PWA قابل للتثبيت — يعمل دون اتّصال بعد التحميل الأوّل محتوى التنزيل • index.html و app.js و styles.css — تطبيق Face Quest Lab كاملاً • face-api.min.js + /models — الأدمغة الذكيّة الثلاثة مضمَّنة • ble_microbit.js + microbit.ts — برنامج Robot Buddy لـ MakeCode • README.md — نظرة عامّة مبسَّطة للأطفال • USERGUIDE.html و .md — دليل إعداد كامل + استكشاف الأخطاء • قابلة للطباعة: بطاقة بدء   4. Robot Buddy — micro:bit V2 حقيقي يُظهر ✓ بجانب حاسوب يُشغِّل Face Quest.
