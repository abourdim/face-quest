Full description

🎮 Face Quest — an AI face recognition game for kids that runs 100% in your browser. Open one HTML file in Chrome or Edge, show your face to the webcam, and the app learns who you are in 3 seconds. Then it unlocks, welcomes you back, and turns learning AI into a gamified quest — with zero data ever leaving your device. WHAT YOU GET • 🧠 Teach My Face flow — enroll a face with a few webcam frames, compute a 128-D descriptor locally • ⚡ Verify / Unlock flow — live webcam match returns MATCH or NO-MATCH in ~200 ms • 🎙 Voice commands — "start", "teach", "unlock", "lock", "reset" via the Web Speech API • 🔊 Speech feedback — the app speaks its own status ("Face learned. You're ready to unlock.") • 🔒 Auto-lock mode — PIN-protected; locks when the face leaves frame, unlocks on a match • 🏆 Quest Log + XP counter — gamified reward loop that keeps kids coming back • 🔁 Front/back camera switch + mirror toggle • 📡 Optional BBC micro:bit V2 over BLE UART — app sends MATCH / NO → ✓ or ✗ on the 5×5 LEDs • 🛡 Privacy-first by design — no cloud, no account, descriptors live only in localStorage • 📱 PWA — installable, offline-capable after first load • 👶 Kid-friendly UI + 🧙 Teacher / parent PIN controls WHAT'S IN YOUR DOWNLOAD • index.html — the full face recognition game • face-api.js models — TensorFlow.js weights bundled locally, no CDN fetch • makecode.ts — optional micro:bit firmware (flash once from MakeCode) • SETUP.md — 5-minute quick-start • docs/ — illustrated guide, teacher lesson plan, FAQ, Etsy playbook • LICENSE — personal / classroom single-user license REQUIREMENTS • Webcam (built-in laptop cam is fine) • Chrome or Edge on desktop (or Chrome on Android) • Microphone (for voice commands — optional but recommended) • BBC micro:bit V2 + Bluetooth (optional, for LED feedback) • HTTPS or file:// — double-clicking the HTML works WHO IT'S FOR Teachers introducing AI in the classroom · home-schooling families · robotics and STEM clubs · parents who want a safe first look at face recognition · anyone curious how face-api.js and TensorFlow.js actually work. PRIVACY FIRST Nothing leaves your computer. Ever. Webcam frames never leave the device. No analytics, no logins, no cloud. The 128-D face descriptor lives only in your browser's localStorage and can be wiped with one click. LIFETIME UPDATES Every version shipped from this listing is yours forever. Re-download the latest ZIP anytime from your Etsy Purchases page. Happy questing! 🚀🧠🎮
