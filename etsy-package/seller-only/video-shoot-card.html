Etsy 60-sec Video Shoot Card Face Quest · Script A

Pre-flight (90s)

  • Webcam plugged in, permissions granted
  • Chrome/Edge open, index.html loaded
  • face-api models cached — page ready
  • Good, even front-light on subject's face
  • Language matches voiceover (EN / FR / AR)
  • micro:bit V2 paired via BLE (optional prop)
  • Kid subject briefed: enroll → lock → walk away → unlock
  • Phone in 9:16 on tripod, front-lit
  • Desk cleared — laptop + webcam + (optional) micro:bit only
  • Captions app ready OR overlay plan
  • Script read once, under 55s
  • Phone silenced, siblings/pets warned

Specs (memorise)

Length≤ 60s (aim 55s)
Aspect9:16 portrait
Res1080 × 1920 min
CodecMP4 / H.264 + AAC
Size< 100 MB
AudioMuted by default → captions mandatory
CoverFirst frame = thumbnail
HookFirst 3s decides the scroll

During recording

  • One scene per phase — don't cut every 2s
  • Switch on words, not mid-sentence
  • 1s pause on MATCH banner
  • Eye contact with lens on CTA
  • Smile for final 3s — loop frame
  • If > 55s, re-cut

The 60-second arc — Script A

TimeSayDo / Click
0–3s "Your face is the key — learn, spot, play, in 60 seconds." Close-up of kid at webcam, browser visible. Overlay: Quest Log "Mission Ready".
3–10s "One page, one face. No account." Click 🚀 Start Mission → camera preview, detection box locks on.
10–20s "Teach My Face — the game remembers you." Click 🧠 Teach My Face. Kid centres face. Banner: ENROLLED. Overlay: XP 0 → 10.
20–30s "Lock it, walk away, come back — Unlock!" 🔒 Lock. Kid exits frame. 5s auto-lock ticker. Returns → 🔓 Unlock! → MATCH.
30–40s "XP climbs. Voice commands. Optional micro:bit goes live." XP counter ticks. Say "Unlock". Micro:bit buzzer + LEDs light on P0 HIGH.
40–50s "Tunable threshold, two math modes, PIN-gated Test Mode. PWA install." Quick shot of Test Mode panel (Euclidean/Cosine, 5–25 frames). Tap Install.
50–55s "Link below — Learn, Spot, Play. Teachers and kids welcome." Face-cam. Eye contact with lens.
55–60s "Happy questing." Hold still. Logo + handle freeze. Loop frame.

On-screen overlays

  • XP counter — top-right, green pill, bumps on MATCH / ENROLLED
  • Quest Log — bottom-left strip: "Mission Ready" → "Face Learned" → "Locked" → "Unlocked!"
  • Status chips — ENROLLED · LOCK · MATCH · NO (mirrors BLE UART messages)
  • Tagline card — final 2s: Learn · Spot · Play

After Stop

  • Watch once, eyes off script
  • Trim to 55s (iMovie / CapCut / DaVinci)
  • Burn in captions — centered below subject
  • Blur any onlooker faces not the hero kid
  • Export MP4/H.264, < 100 MB
  • Upload · verify autoplay · phone + sound off

Props & framing

  • Hero: kid (8–12), centred, shoulders up
  • Laptop webcam OR external USB cam at eye level
  • Soft key-light 45° front; no backlight window
  • Plain wall behind — no faces in background
  • Optional: micro:bit V2 on desk, buzzer audible
  • B-roll: over-shoulder shot of MATCH banner
