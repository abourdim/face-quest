Face Quest Controls

Cheat Sheet — Laminate Me!
Print → Laminate → Stick next to the lab computer
Mission Buttons
🚀 StartTurn on the webcam & load AI models
🧠 TeachEnroll your face (collects sharp samples)
🔓 UnlockVerify 1:1 against the saved face
🔒 LockReturn to the locked state manually
🧹 ResetDelete the saved enrollment
Camera & Preview
🔁 SwitchCycle to the next available camera
🪞 MirrorFlip preview left/right
🧾 Copy LogCopy the Quest Log to the clipboard
🧹 Clear LogWipe the on-screen log
Voice Commands (click 🎤 Voice)
"Start"Start the webcam mission
"Teach" / "Enroll"Begin enrollment
"Unlock" / "Verify" / "Open"Run verify
"Lock"Lock the app
"Reset" / "Clear"Delete the saved face
Tuning Knobs
DetectorSSD (accurate) or Tiny (fast)
DistanceEuclidean or Cosine similarity
Threshold0.30 – 1.20 • lower = stricter match
Verify Frames5 – 25 • how many frames to average
Test Mode (PIN-gated)
🔑 Set PINCreate or change the 4-digit PIN
🧪 Test ModeContinuous verify loop (demo/debug)
0–9 / Enter / EscPIN pad keyboard support
micro:bit BLE State
Disconnected — click 🤝 Connect to pair
Pairing — pick "BBC micro:bit [xxxxx]"
Connected — MATCH / NO messages flow
Error — re-flash firmware, re-pair
UART Messages (app → board)
MATCHUnlock succeeded • P0 HIGH, ✓ icon
NOUnlock failed • P0 LOW, ✗ icon
ENROLLEDFace was just taught • ❤ icon
LOCKManual lock • P0 LOW, ✗ icon
TESTConnection ping • shows "T"
Pro Tips
Raise Threshold if "No Match" is too strict; lower it if strangers are getting in. Only Chrome / Edge (desktop) support Web Bluetooth for the micro:bit.
