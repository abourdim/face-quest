Face Quest

In-browser face recognition lab • webcam + optional BBC micro:bit V2
v1.0.0 • Digital Download
Thank you for buying Face Quest! You just grabbed a zero-install, zero-account face recognition classroom in a folder. Three tiny AI models run entirely in your browser — no photos saved, no cloud, no telemetry. This page walks you through the first three things to do.

First 3 Things To Do

1
Serve the folder. Open a terminal in the project folder and run python3 -m http.server 8012. Then visit http://localhost:8012 in Chrome or Edge. (A plain file:// open won't let the browser grant camera permission.)
2
Start Mission. Click 🚀 Start Mission and allow camera access. The three AI models load from ./models. Click 🧠 Teach My Face, then 🔓 Unlock!.
3
Pair a Robot Buddy (optional). Flash the provided microbit.ts to a BBC micro:bit V2, click 🤝 Connect. On every Unlock the board shows ✓ / ✗ and drives pin P0 HIGH on MATCH.

Requirements

✓Webcam (built-in or USB)
✓Chrome 90+ or Edge 90+ on desktop (getUserMedia + Web Bluetooth)
✓A way to serve the folder over HTTP (python3 -m http.server works)
✓Optional: BBC micro:bit V2 for the Robot Buddy link
✓No internet needed after first load — installs as a PWA

Key Features

Detect: face detector (SSD or Tiny) • 68 facial landmarks • 128-number face descriptor

Enroll & Verify: 1:1 matching • Euclidean or Cosine distance • tunable threshold 0.30 – 1.20

Play: XP counter • PIN-gated Test Mode • auto-lock after 5 s of no face • Speech feedback & voice commands

Robot Buddy: BLE UART micro:bit link • MATCH / NO / ENROLLED / LOCK / TEST messages • P0 HIGH on match

Privacy

100% Local — No Photos Saved

face-api.js runs entirely in your browser. The only thing stored locally is a 128-number descriptor in IndexedDB — not a photo. No accounts, no cloud, no tracking. Safe for classrooms.
