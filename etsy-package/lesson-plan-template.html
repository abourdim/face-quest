Sample Lesson: How Does a Face Become a Password?

Ready-to-teach 45-minute AI intro
How Does a Face Become a Password?
45 minutes
Ages 9–14
AI Literacy / Computing / Ethics
Learning Objectives
1. Explain, in plain words, what a face detector, landmarks model, and recognition model each do.
2. Enroll and verify their own face using the Face Quest app.
3. Describe why the threshold slider changes MATCH / NO MATCH results.
4. Discuss one privacy-friendly design choice of the app (everything stays local).

Face Quest features used in this lesson

  • Start Mission loads face-api.js models locally from ./models
  • Teach / Unlock 1:1 enrollment and verification with live samples
  • Threshold & Detector Euclidean / Cosine, SSD (accurate) vs Tiny (fast)
  • BLE micro:bit MATCH / NO over UART, P0 HIGH/LOW, ✓ / ✗ icons
  • Quest Log timestamped, color-coded events for classroom discussion
